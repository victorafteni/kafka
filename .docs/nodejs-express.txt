Pentru a porni backend-ul Node.js + Express, ai următoarele variante simple (din terminalul deschis în proiect):

Varianta 1: Din rădăcina proiectului (Cea mai simplă)

Rulează direct din folderul principal:

powershell

npm run backend

(sau npm run backend:dev dacă vrei reîncărcare automată la modificări de fișiere).

(sau node backend/src/server.js)

Varianta 2: Cu Auto-Reload la orice modificare de cod (Development)

Dacă modifici fișiere în backend și vrei ca serverul să se reîncarce automat:

powershell
node --watch backend/src/server.js
Varianta 3: Din folderul backend/
powershell
cd backend
npm start

(sau npm run dev pentru modul cu auto-reload)

💡 Verificare rapidă dacă rulează:

Deschide în browser sau testează în PowerShell:

http://localhost:3000/api/health
 
→
→ afișează {"status":"ok","redis":"connected"}.
http://localhost:3000/api/catalog
 
→
→ returnează produsele și categoriile direct din Redis.

Notă: Dacă primești eroarea EADDRINUSE: address already in use :::3000, înseamnă că serverul rulează deja pe portul 3000. Poți opri procesul anterior cu:

powershell
Stop-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess -Force
